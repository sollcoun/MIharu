# Руководство пользователя — Miharu (見張る)

**See what changed. Understand what matters.**

Miharu — локальный Windows Security Monitor. Программа делает снимок системы, сравнивает его с прошлым сканом, оценивает риски и объясняет результаты. Данные остаются на вашем ПК.

## Требования

| | |
|--|--|
| ОС | Windows 10 / 11 x64 |
| Python | **Не нужен** (входит в установщик) |
| Права | Установка — администратор; ежедневная работа — обычный пользователь |
| Сеть | Не обязательна (нужна только для Telegram, VirusTotal, AI) |

---

## Установка

1. Запустите `Miharu-Setup-1.1.0.exe`
2. Следуйте мастеру установки
3. Откройте **Miharu** из меню «Пуск»

| Что | Где |
|-----|-----|
| Программа | `C:\Program Files\Miharu` |
| Отчёты, настройки, логи, снимки | `%LOCALAPPDATA%\DiskDiagnostic` |

Старые установки **Disk Diagnostic** при обновлении удаляются автоматически (совместимый AppId).

## Быстрый старт

| Шаг | Действие |
|-----|----------|
| 1 | Выберите диски (кнопка выбора дисков), если нужно не все |
| 2 | Нажмите **Quick** (быстрее) или **Full** (глубже) |
| 3 | Дождитесь окончания скана — статус в окне и в логе |
| 4 | Откройте **Dashboard** — HTML-отчёт в браузере |
| 5 | По желанию: **TELEGRAM** → Start у бота; **MONITOR** → фон |

## Режимы сканирования

| Режим | Когда использовать |
|-------|--------------------|
| **Quick** | Ежедневная проверка, фоновый Monitor |
| **Full** | После инцидента, при подозрении, периодический полный аудит |

Системные проверки (процессы, службы, задачи, автозагрузка) выполняются **независимо** от выбранных дисков. Диски влияют на обход файловой системы.

## Как читать результат

### Статус системы

| Статус | Смысл |
|--------|--------|
| **PROTECTED** | Критических угроз нет, система под наблюдением |
| **ATTENTION** | Есть MEDIUM — стоит разобрать findings |
| **AT RISK** | Есть HIGH — требуется внимание |

Риск: **LOW / MEDIUM / HIGH**. Confidence — насколько engine уверен в оценке.

### Изменения с прошлого скана

Блок показывает, что появилось с предыдущего снимка:

- новые процессы  
- автозагрузки  
- службы  
- задачи планировщика  
- подозрительные файлы  
- изменения объёма диска  

### Новые процессы

Для каждого процесса показывается:

- имя файла  
- краткое описание на русском (что это за компонент Windows / ПО)  
- при наведении — полный путь  

Если описание «неизвестный / сторонний процесс» — стоит проверить путь и издателя.

### Findings (MEDIUM / HIGH)

Объекты, которые Risk Engine считает заслуживающими внимания.  
Клик по строке (в дашборде) открывает **explain**: какие evidence дали баллы и почему.

### Process trees

Цепочка parent → child для интересных (unsigned / elevated) процессов. Помогает понять, *кто* запустил процесс.

### Пояснение (AI)

Текстовое резюме на русском. AI **не** выставляет уровень угрозы — только формулирует вывод по уже посчитанным рискам.

## Telegram

В офисной сборке токен бота уже внутри установщика.

1. Нажмите **TELEGRAM** в приложении  
2. Откроется чат с ботом в Telegram  
3. Нажмите **Start**  
4. Дождитесь сообщения «Чат успешно привязан»

После этого алерты (HIGH, новая persistence) будут приходить в этот чат.

Один бот на команду; у каждого ПК — свой chat (или общая группа).

## Фоновый Monitor

1. Нажмите **MONITOR**  
2. Создаётся задача в Планировщике Windows  
3. По интервалу (по умолчанию каждые несколько часов) выполняется Quick-скан  
4. В Telegram уходят только важные события (HIGH / новая persistence), не каждый скан

Выключение — снова **MONITOR** (кнопка с галочкой).

## Где лежат данные

```text
%LOCALAPPDATA%\DiskDiagnostic\
  Config\          settings.json, installation_id
  Reports\         отчёты сканов
  History\         история
  Snapshots\       снимки для diff
  Cache\
  Logs\
  Alerts\          состояние Telegram
```

Отчёты можно копировать коллегам: в них **нет** bot token и полных сырых dumps.

## Настройки (для продвинутых)

Файл: `%LOCALAPPDATA%\DiskDiagnostic\Config\settings.json`

| Ключ | Описание |
|------|----------|
| `notification_mode` | `off` · `direct` · `backend` |
| `telegram_bot_token` | задаётся установщиком / product_defaults |
| `telegram_chat_id` | после кнопки TELEGRAM |
| `selected_drives` | например `["C:", "D:"]` |
| `monitor_interval_hours` | интервал фона |
| `monitor_smart` | Full только при триггере |
| `vt_api_key` | VirusTotal (опционально) |

Обычно править вручную не нужно — хватает кнопок в UI.

## Устранение неполадок

| Симптом | Что проверить |
|---------|----------------|
| Не запускается | Переустановить Setup; антивирус не блокирует `Miharu.exe` |
| Скан долго / «висит» | Full на большом диске занимает время; смотрите лог в окне |
| «Bot token не задан» | Нужна офисная сборка с `product_defaults.json` или ручная запись токена в settings |
| Telegram не привязывается | Сеть, бот не заблокирован; снова **TELEGRAM** → Start |
| Окно «Не отвечает» при Telegram | Обновите до версии с фоновой привязкой; не закрывайте окно, дождитесь диалога |
| Нет дашборда | Сначала успешно завершите хотя бы один скан |

---

## Конфиденциальность

- Сканирование и оценка рисков — **локально**  
- Telegram получает только текст алерта, не весь отчёт  
- AI (если включён) используется для пояснений, не для выставления risk level  

Вопросы по развёртыванию в офисе — к администратору, который собирал Setup.
